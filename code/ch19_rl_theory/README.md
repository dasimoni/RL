## Headline results (full runs, default seeds)

- **Step-size constant** (Part 0, mean estimation with α = c/n started at the mean, 4,000 runs): RMSE slopes over n = 10^2..10^5 are −0.099 (c = 0.1), −0.293 (c = 0.3), −0.444 (c = 0.5) and −0.501 (c = 1): the noise decays like n^-c when c < 1/2 and like n^-1/2 when c > 1/2.
- **Q-learning step sizes** (random MDP, S = 8, A = 3, 10 runs; ||q*|| = 8.52 at γ = 0.9, 83.9 at γ = 0.99). Mean ||Q_n − q*||∞ at γ = 0.99 after 10^6 iterations: 1/n 72.39, 1/n^0.8 39.54, rescaled linear 1/(1+(1−γ)n) 0.0193, constant 0.1 0.654, constant 0.01 0.141. The 1/n error follows the one-state prediction n^-(1−γ): fitted slopes −0.101 (γ = 0.9) and −0.010 (γ = 0.99); the product (19.9) at n = 10^6 is 0.866 against a measured ratio 0.863.
- **Lemmas**: PDL residuals 9.4e-15 (discounted) and 2.2e-15 (finite horizon); simulation lemma residuals 1.6e-15; simulation bounds hold with actual/bound ≤ 0.117 (finite horizon) and ≤ 0.011 (discounted); greedy loss ≤ 0.273 of the bound 2ε/(1−γ) on a random MDP, 0.995 of it in the tight two-action example; approximate VI with a constant +ε error, started from Q_0 = 0, reaches the limit ε/(1−γ) = 0.1000 after 400 iterations (independent uniform errors: 0.021).
- **Concentration and the generative model**: Bernstein radius (b = max(p, 1−p)) 0.051 vs Hoeffding 0.136 for Bernoulli(0.01), 0.148 vs 0.136 for Bernoulli(0.5); 50 simultaneous Hoeffding intervals at per-arm δ = 0.05 all hold in only 72.1% of trials (99.6% with δ/50). Theorem 19.8 held in 700/700 runs, but bound (19.18) is 187–234× the mean Q̂ error and bound (19.19) is 248× (N = 10) to 1,687× (N = 10^4) the worst policy loss; error slope in N −0.497. Hard instance: RMSE ∝ (1−γ)^-1.54 (theory −1.5), matching the delta method to 3 digits (0.3227 vs 0.3226 at γ = 0.99, N = 10^6); random dense MDP: exponent 0.88. Finite-horizon hard instance: RMSE ∝ H^1.04 while the Hoeffding bound ∝ H^2.
- **Regret** (30,000 episodes, 10 runs). Lock (S = 7, A = 2, H = 9, V* = 3): ε-greedy 77,279 (ε = 0.1) and 77,073 (ε = 1/√k), both linear (Reg(K)/Reg(K/2) = 2.00, 1.99); UCB-H Q-learning c = 1: 82,325 (never reaches the goal: a tried action's estimate r + V + b exceeds the untried action's H − h until b ≈ 1, so the second action in the start state is first tried only at episode 14,655–16,477); c = 0.1: 28,991 (ratio 1.29; second action first tried at episode 148–175); UCBVI c = 0.1: 732 (ratio 1.04). Random MDP (S = 5, A = 3, H = 5): 3,864 / 2,814 / 28,088 / 3,055 / 892 in the same order. Lock diagnostics for the ε-greedy agents: 8/10 (constant ε) and 5/10 (decaying ε) runs reach the goal, 1–2 times each in 30,000 episodes; exact P(π_k reaches the goal) for constant ε is 5.0e-4, 3.0e-5, 5.9e-6 at k = 100, 1,000, 30,000; 17% / 31% of the reachable lock entries are still tied at the end. `--lock-seed-check` (seeds 0–2): 1 of 60 ε-greedy runs learned the lock (seed 2, decaying ε, 28,937 goal episodes).
- **Policy gradients** (S = 10, A = 4, γ = 0.9, exact gradients). Gap after 10^5 iterations: softmax PG with the theory step (1−γ)^3/8 still 1.10; η = 1: 8.7e-5 (with a plateau, t·gap = 44.7 at t = 10^4, min optimal-action probability 0.009); η = 10: 7.5e-6 with t·gap between 0.75 and 0.98 from t = 10 to 10^5. NPG with η = 0.1 / 1 reaches gaps below 1e-10 by checkpoint t = 1,661 / 131; the NPG bound (19.29) held at every checkpoint (at T = 100: bound 1.01, gap 1.2e-9 for η = 1). Distribution mismatch: softmax PG (η = 1) on V(μ_β) first gets below a gap of 1e-3 at t = 47,784 for β = 1 (D∞ = 2.9), not within 10^5 iterations for β = 0.1, 0.01 (final gaps 3.9e-3, 4.75e-3). All gaps are those of the policy after exactly t updates. Gradient domination ratio ≤ 0.656; Łojasiewicz ratio ≥ 1.155.
- **Offline RL** (S = 10, A = 4, γ = 0.9, 100 datasets per point). Mostly-expert data (C* = 3.1, C_all = 311): plug-in suboptimality 0.455, 1.551, 1.273, 0.038 at N = 100, 500, 1,000, 30,000; VI-LCB and BC exactly optimal in all 800 datasets. ## Implementation notes

- `regret_experiment.py` computes regret exactly (and, on the lock, the exact probability that the episode policy reaches the goal, by forward dynamic programming): each agent's policy is fixed during an episode (step h is visited once per episode and Q_h is only updated after it is used), so the expected value of the episode policy, including ε-randomization, is computed by backward induction in the true MDP. All Q-learners use the step size (H+1)/(H+t) of Jin et al. (2018) and clip the next-state value at the remaining horizon H − h − 1 (Q itself is not clipped, as in Jin et al.; UCBVI clips its optimistic Q at H − h). Greedy ties are broken at random afresh in every episode.
- UCB-H and UCBVI keep step-dependent counts (time-inhomogeneous setting), although both test MDPs happen to have step-independent transitions.
- `offline_pessimism.py` never selects an action that has no data (Q = −∞), clips V at 0 from below (true values are non-negative, so V stays a lower bound), and with penalty constant c = 0 reduces to plug-in planning on the observed pairs.
- `q_learning_rates.py` and `exercise_solutions.py` (Ex. 13) use common random numbers across step-size schedules, so differences between schedules are not due to different samples.
- `q_learning_rates.py` and `pg_convergence.py` record results on log-spaced checkpoint grids that contain every power of 10 exactly, so the reported columns n (or t) = 10^k are the iterates at exactly that n (or t).
