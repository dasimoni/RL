# Chapter 12 code: off-policy actor-critic for continuous control (DDPG, TD3, SAC)

Companion code for [Chapter 12](../../chapters/12-continuous-control-actor-critic.md). Everything is written from scratch in NumPy/PyTorch (CPU, one thread). The deep-RL experiments use Gymnasium's `Pendulum-v1`, with actions rescaled to [-1, 1].

Run every script from the repository root. `--quick` is a smoke test that writes no figures. The full run reproduces the chapter's numbers and figures in `figures/`.

Runtimes were measured on a shared 4-core machine while other jobs were running, with one thread per script. Expect them to be shorter on an idle machine.

Notes:

* `td3.py` saves its learning curves to `figures/{td3,ddpg}_pendulum_curves.npz` (and a figure) only for the default settings; the `--noise`, `--expl-noise`, `--nstep` and `--total-steps` variants print results but write nothing. `sac.py` overlays the TD3 and DDPG mean curves when those files exist, so run `td3.py` and `td3.py --algo ddpg` first.
* `overestimation.py` saves its measurements to `figures/overestimation_data.npz`.
* All agents bootstrap through time-limit truncation: Pendulum episodes are always truncated after 200 steps and never terminate. The n-step variant flushes its window at the end of every episode and still bootstraps after a truncation.
