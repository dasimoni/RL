## Headline results (full runs, default seeds)

- **DeepSea** (5 seeds, cap 4,000 episodes; "solved" = 10 of the last 20 episodes reach the treasure):
  - A uniformly random policy first finds the treasure after a median of 9, 19, 131 and 999 episodes for N = 4, 6, 8, 10 (theory: about 0.69 * 2^N). Eps-greedy Q-learning solves N = 4 (median 98 episodes) but never finds the treasure at N = 6: the small move cost teaches it to go left.
  - Median episodes to solve N = 40: UCB-Q 2,034, RLSVI 609, ensemble + randomized prior 2,667. PSRL (run up to N = 30) needs 1,840 at N = 30. Fitted growth T_solve ~ N^p for N >= 10: p = 2.41 (UCB-Q), 2.53 (PSRL), 1.77 (RLSVI), 2.44 (ensemble + prior).
  - Ablations: bootstrapping without a prior (masks 0.5) finds the treasure in 3 of 5 runs at N = 4 and 1 of 5 at N = 6. Zero-initialized members without masks are bit-identical (checked: max |Q_k - Q_0| = 0), i.e. greedy Q-learning, and find it in 1 of 5 runs at N = 4. Redrawing the ensemble member every step is 4-5x slower than per-episode commitment from N = 10 (450 vs 99 episodes; one run censored), then fails in 4 of 5 runs at N = 16. Bootstrap masks with p = 0.5 slow learning about fivefold (2,495 vs 511 episodes at N = 20).
  - UCB-Q bonus scale at N = 20 (median episodes to solve): 238, 241, 263, 353 and 1,487 for beta = 0, 0.01, 0.03, 0.1, 0.3; every run censored at beta = 1. DeepSea is deterministic, so optimism about untried actions (beta = 0) suffices.
- **RiverSwim** (20 seeds, 2,000 episodes, H = 20, V* = 3.0645): cumulative regret 5,944 (eps-greedy, stuck 20/20), 4,745 (optimistic certainty equivalence without bonus, stuck 16/20, best run 7.9), 579 (model-free UCB-Q, step-indexed tables, beta 0.3), 132.0 (UCBVI-style with step-indexed counts n_h(s,a,s')), 16.9 (UCBVI-style with counts pooled over h) and 46.7 (PSRL, pooled). The 34x gap between UCB-Q and the pooled model-based agent splits into about 7.8x from pooling data across the 20 steps and 4.4x from having a model. Bonus sweep (10 seeds), pooled model-based: 15.4, 15.4, 16.3, 33.4, 123.0 for beta = 0.03, 0.1, 0.3, 1, 3; model-free: 455, 561, 629, 965, 2,242. UCB-Q with an integer Q-table (Pitfall 7): regret 5,971.5 vs 723.5 with a float table (5 seeds).
- **RND gridworld** (5 seeds, 500 episodes x 100 steps): distinct cells visited out of 328 after 83 / 500 episodes: no bonus 143.0 / 226.4, count bonus 235.2 / 323.4, RND 280.0 / 310.4, uncentred count bonus 40.2 / 91.0. The goal is never found without a bonus (or with the uncentred bonus), and is found in every bonus run (count: episodes 97-326; RND: 83-134). Greedy evaluation on Q_E succeeds in 100% of the last 50 episodes for every bonus agent. Behaviour-policy goal rate over the last 50 episodes: count 0.44 (the agents loiter at (18, 19), next to the goal, in 4 of 5 runs), RND 0.96; with the intrinsic return stopped at the goal, count 0.97, RND 0.96. RND error vs visit count: Spearman rho from -0.54 to -0.83; unvisited cells have errors of about 4e-4 against 3e-7 to 2e-6 for the 10% most-visited.
- **Noisy TV** (5 seeds, 200 episodes, C = 10 channels): share of steps on the TV over the last 50 episodes: forward-model curiosity 0.899, count bonus 0.017, RND 0.004. Cells explored: 69.4, 273.4 and 297.6 of 328. The measured forward-model error of "press" at the TV is 0.947, as predicted for an EMA predictor (minimum possible 0.9).
- **Exercises**: after 4,000 training episodes at N = 10, eps-greedy has learned "left" on only 3-4 diagonal cells, and its exact per-episode success probability is 1e-7 to 1e-6 (not (eps/2)^N = 1e-13). Random-walk lock times match 2^(N+1) - 2 (e.g. 509.8 +- 1.6 vs 510 for N = 8, 100,000 walkers). Boltzmann exploration behaves like the random walk for tau >= 0.01, and at tau = 0.001 it is strongly biased towards "left" (median run never finds the treasure for N >= 6). SimHash on 2-D inputs yields at most 2k codes. Go-Explore on DeepSea first finds the treasure after a median of 251, 1,676 and 3,632 episodes for N = 10, 20, 30.

## Implementation notes

- All Q-learners on DeepSea and RiverSwim use the step size (H+1)/(H+n) of Jin et al. (2018). DeepSea agents, and the RiverSwim Q-learners, update at the end of each episode in reverse order (on DeepSea each state is visited at most once per episode, so this is ordinary Q-learning).
- RiverSwim: UCB-Q keeps one table Q_h and count n_h per step h (as in Jin et al.). The pooled UCBVI-style agent and PSRL assume time-homogeneous dynamics and pool all transitions of (s, a) over h; the time-indexed UCBVI-style agent does not. Compare all three before attributing differences to "model-based vs model-free".
- The tabular intrinsic-reward agents (`explore_lib.py`) update online and replay each episode once in reverse. They **centre** the intrinsic reward by its running mean. Without centring, a zero-initialized intrinsic value table makes tried actions look better than untried ones, and the agent explores less than a random walk (`--no-centre`; Chapter 14, Sec. 7.3).
- RND normalisation: the raw error is divided by a running std of the raw per-step errors (not of the intrinsic return, as in the paper) and clipped to [0, 10]; the running statistics are **warm-started** from the errors of all states under the initial predictor. An earlier version started them at zero, which produced rewards of about 1e6 whenever the first two errors were equal and corrupted whole runs (Chapter 14, Pitfall 4). The clip never triggered in the reported runs.
- The intrinsic value stream is non-episodic by default, as in RND: after a termination (reaching the goal) it bootstraps from the start state. `TwoStreamQ(..., intrinsic_at_goal="stop")` ends the intrinsic return at termination instead. A truncation (time limit) is handled by partial-episode bootstrapping from the next state in **both** streams: the time limit is not part of the state, so treating a timeout as a jump to the start would make the stream non-Markov, whereas termination happens exactly at the goal cell.
- Exploitation is measured by separate greedy evaluation episodes on Q_E alone (beta = 0, eps = 0, every 5 episodes, with their own random generator so training is unaffected), not by the exploratory behaviour.
